# 選做實作：MAX7219 點陣模組

> 預告頁｜對應主線：[74HC595：辨識並驅動裸 8×8 點陣](06-74hc595-8x8點陣.md)

!!! info "即將推出"
    本頁目前暫緩，尚未提供可操作教材內容。

預計會在取得並驗證指定模組後，提供兩種控制模式的完整選做實作：`LedControl` 的軟體序列控制，以及 ESP32 硬體 SPI 的 `SPI.begin()`／`SPI.transfer()`。兩種模式都會以相同的固定圖樣比較接線、亮度、方向與輸出結果，並各自提供核心功能速覽、單片與多片串接限制及故障分流。

實測後會依兩種模式能否共用接線、基本成果與安全檢查，決定將它們放在同一章的兩個模式，或拆成兩篇獨立選做頁。

本頁會清楚比較 MAX7219 與主線裸點陣＋74HC595 的責任差異，但不會把額外模組變成主線材料或完成成果的必要條件。

完成前，請先依主線完成裸 8×8 點陣顯示。
