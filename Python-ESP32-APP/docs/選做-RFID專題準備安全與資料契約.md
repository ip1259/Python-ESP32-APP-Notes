# 選做專題：準備、安全與資料契約

> 預告頁｜先認識 RFID 門禁系統選做專題的資料流、安全界線與後續章節方向。

!!! info "即將推出"
    本頁正在整理專題的虛構資料範例、遮蔽規則與失敗情境；尚未提供可操作的硬體、網路或程式教材。

這個選做專題會把讀卡事件、狀態判斷與不同裝置上的顯示串成一條資料流。開始前會先約定各端可以交換哪些必要資訊，避免把完整卡片識別值、帳密或內部設定帶進訊息、畫面與紀錄。

專題只用於已授權練習卡的讀卡狀態管理與顯示。它不連接，也不控制繼電器、電磁鎖、馬達或任何實體門控設備；因此不能當作真實門禁系統。

預計內容包括：如何閱讀專題資料流、為何要遮蔽識別資料、授權與未授權狀態的意義，以及遇到讀卡、連線或程式停止時應保留「未知或失敗」狀態的原因。

這是主線完成後才可閱讀的選做方向，不影響環境看板的核心成果。你可先完成[整合專題：完成環境看板](08-整合專題.md)，再等待後續章節發布。
