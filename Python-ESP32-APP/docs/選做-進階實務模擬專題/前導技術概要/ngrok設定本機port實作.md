# 即將推出：選做實作｜ngrok 設定本機 port

> 預告頁｜本頁將獨立練習 ngrok 的安裝、帳號設定、指定本機 port 與停止方式。

!!! info "即將推出"
    ngrok 的帳號流程、免費方案與 Windows Agent 畫面仍需依目前版本完成確認。本頁尚未提供可直接操作的命令與畫面。

預計以一個練習用 port 認識暫時通道指向哪裡，以及如何停止通道。完成這頁不需要 FastAPI、ESP32、MQTT、手機或其他前導實作。

如果另外完成 FastAPI Hello World，未來可在頁尾選擇把兩者串接；這不會成為 ngrok 實作的必要步驟。

目前可先閱讀[ngrok：暫時公開通道的概念](ngrok暫時通道概念.md)。
