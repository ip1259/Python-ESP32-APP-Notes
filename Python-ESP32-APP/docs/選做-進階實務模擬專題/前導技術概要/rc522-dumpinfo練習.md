# 即將推出：選做實作｜用 DumpInfo 認識 RC522 與練習卡

> 預告頁｜本頁將使用 `MFRC522` 內附的 `DumpInfo` 與專用練習卡，確認 RC522 的基本通訊。

!!! info "即將推出"
    `DumpInfo` 會顯示卡片 UID 與可讀區塊；不同模組與卡片也可能有差異。本頁暫不提供可直接操作的接線與讀卡步驟。

正式實作只會使用自己明確授權、近乎空白的 MIFARE Classic 練習卡。悠遊卡、信用卡、學生證、門禁卡、他人卡與來源不明卡都不在練習範圍內。

這頁不會寫入或複製卡片，也不會保存、截圖或傳送實際 UID 與卡片內容。它不需要 FastAPI、ngrok、Thunkable、MQTT 或 BLE。

目前可先閱讀[SPI 通訊與多裝置](spi通訊與多裝置.md)及[RC522 與 MFRC522 函式庫](rc522與mfrc522函式庫.md)。
