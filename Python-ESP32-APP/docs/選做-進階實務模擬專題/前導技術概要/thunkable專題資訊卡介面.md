# 即將推出：選做實作｜Thunkable 專題資訊卡介面

> 預告頁｜本頁將獨立建立一個沒有資料功能的靜態 App 介面。

!!! info "即將推出"
    Thunkable 的帳號條件、Design 畫面與 Web Preview 仍需依目前版本完成確認。本頁尚未提供可直接操作的步驟與截圖。

預計使用一個垂直排列容器與三個文字元件，做出「進階實務模擬專題」資訊卡。畫面會明確顯示「此畫面尚未連線到裝置或服務」。

這個介面不使用 Blocks、按鈕功能或 Web API，也不需要 FastAPI、ngrok、BLE、ESP32 或手機。

目前可先閱讀[Thunkable：App 與 Web API 的概念](thunkable與web-api概念.md)。
