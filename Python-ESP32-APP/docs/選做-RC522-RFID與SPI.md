# 選做實作：RC522 RFID 與 SPI

> 預告頁｜RC522 會用已授權的練習卡，讓你認識 ESP32 的 SPI 資料讀取流程。

!!! info "Coming soon"
    本頁正在確認 RC522 模組接線、`3.3V` 電源條件、函式庫與受控讀卡流程，尚未提供可操作教材內容。

預計內容包括 `SCK`、`MOSI`、`MISO`、`SS`／`SDA` 與 `RST` 的角色、與 74HC595 同步序列輸出的差異，以及以遮蔽資料讀取授權練習卡的安全流程。

RC522 的 `SDA` 在此通常表示 SPI 的 `SS`／片選，不是 I2C 的資料線。完成前請先依主線完成 UART、資料處理與顯示成果；本選做不屬於課程必做、驗收或成績要求。
