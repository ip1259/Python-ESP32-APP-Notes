# 延伸選讀：函式、類別與責任分工

用函式處理一件清楚的工作、用類別保存相關狀態，讓整合程式更容易閱讀與除錯。

- 使用類別保存最新感測讀值與相關方法。

## 函式：一個名稱對應一個工作

第 8 節的 `temperature_status(temp_c)` 負責把溫度轉為狀態文字；`refresh()` 則負責協調讀取、記錄與介面更新。函式的參數與回傳值讓呼叫位置知道資料從哪裡進來、會得到什麼結果。

```python
# 執行位置：Python／電腦
# 檔名：functions_classes_demo.py
def temperature_status(temp_c: float) -> str:
    if temp_c >= 30.0:
        return "偏高"
    return "正常"


status: str = temperature_status(30.0)
print(status)
```

預期結果：顯示 `偏高`。`temp_c: float` 表示溫度是小數，`-> str` 表示函式回傳文字；但仍要在讀取外部資料時實際檢查是否真的是數值。

## 類別：保存一筆相關狀態

目的：將最新溫度、濕度和操作它們的方法放在同一個物件中，而不是散落成許多全域變數。

```python
# 執行位置：Python／電腦
# 檔名：functions_classes_demo.py
from dataclasses import dataclass


@dataclass
class LatestReading:
    temperature_c: float
    humidity_pct: float

    def update(self, temperature_c: float, humidity_pct: float) -> None:
        self.temperature_c = temperature_c
        self.humidity_pct = humidity_pct

    def summary(self) -> str:
        return f"{self.temperature_c:.1f}°C，{self.humidity_pct:.1f}%"


reading: LatestReading = LatestReading(26.5, 61.0)
reading.update(30.0, 58.5)
print(reading.summary())
```

預期結果：顯示 `30.0°C，58.5%`。`update()` 只更新狀態，`summary()` 只產生摘要，這就是單一職責。

## 何時用函式，何時用類別？

| 情況 | 優先選擇 | 例子 |
| --- | --- | --- |
| 只根據輸入算出結果 | 函式 | 溫度轉成「正常」或「偏高」 |
| 需要保存多個會一起更新的值 | 類別 | 最新溫度、濕度與摘要 |
| 一個函式同時讀序列埠、寫 CSV、畫圖 | 拆分責任 | 分成讀取、儲存、繪圖函式 |

## 常見問題

### 呼叫函式後得到 `None`

先檢查函式是否有 `return`。`update()` 的回傳型別是 `None`，它的工作是改變物件狀態；要取得文字請呼叫 `summary()`。

### 類別變得很大、什麼都負責

先列出每個方法在做什麼。若同時處理讀取、檔案、圖表和介面，請依責任拆成不同函式或類別，而不是繼續累加。

## 重點整理

- 函式用參數接收資料、用回傳值交出結果。
- 類別將相關狀態與操作集中，但不應承擔所有責任。
- 基本 Type Hint 提升可讀性，外部資料仍需要實際檢查。
