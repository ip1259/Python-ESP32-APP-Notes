# 選做專題第 5 章：MIT App Inventor、ngrok 與手機無線控制

> 預告頁｜認識手機如何在受控範圍內查詢最新狀態，並送出預先定義的顯示指令。

!!! info "即將推出"
    本頁正在確認 App 範本、Gateway API、暫時 HTTPS 網址、裝置與網路條件；尚未提供可操作的 App、公開網址或設定教材。

預計會說明 MIT App Inventor 在本專題的查詢角色，以及 ngrok 如何暫時讓手機連到 Gateway。手機只能查詢必要的最新狀態，或送出例如「回到待機顯示」這類預先定義的顯示狀態指令。

公開網址、帳密、token、內網位址與讀卡識別資料不會出現在教材或紀錄中。網址外流、網路來源或裝置權限無法確認時，應停止這項選做實作；本章不控制任何實體門控設備。
