# 用 uv 建立 Python 虛擬環境

這一頁會建立本課專用的 Python 專案環境。完成後，你可以用 `uv run` 執行程式，不必把套件安裝到電腦的全域 Python。

## 你會學到什麼

- 使用 `uv` 建立 Python 3.12 專案與虛擬環境。
- 安裝本課會使用的 Python 套件。
- 使用 `uv run` 執行 Python 程式。
- 讀取一筆 JSON 格式的感測資料。

## 開始前

| 項目 | 需求 |
| --- | --- |
| 作業系統 | Windows 10 |
| Python | 3.12 |
| 終端機 | PowerShell |
| 網路 | 安裝 `uv` 與套件時需要網路 |

!!! note "什麼是虛擬環境？"
    虛擬環境（virtual environment）是放在專案資料夾內、專門給這個專案使用的 Python 套件空間。不同專案可以使用不同版本的套件，彼此不會互相影響。

!!! warning "請在自己的課程資料夾操作"
    不要把本課套件安裝到全域 Python。請依照本頁步驟建立專案資料夾，後續程式都放在這個資料夾中。

## 成功的樣子

完成本頁後，你的專案資料夾會有下列重要檔案：

```text
aiot-course/
├─ .venv/             # 本課的虛擬環境
├─ .python-version    # 指定使用 Python 3.12
├─ pyproject.toml     # 記錄本課需要的套件
└─ uv.lock            # 固定套件版本，讓每台電腦安裝結果一致
```

你也會看到下列成功訊息：

```text
套件匯入成功！
```

## 步驟 1：安裝或確認 uv

**目的：** `uv` 會協助我們建立虛擬環境、安裝套件與執行程式。

執行位置：PowerShell／電腦

```powershell
winget install --id=astral-sh.uv -e
```

安裝完成後，請關閉並重新開啟 PowerShell，再執行：

```powershell
uv --version
```

預期結果：顯示 `uv` 的版本號，例如 `uv 0.x.x`。

!!! tip "已經安裝過 uv？"
    如果 `uv --version` 已經能顯示版本號，可以跳到下一步。

### 找不到 `winget` 怎麼辦？

請先詢問教師或助教。也可以依照 [uv 官方安裝說明](https://docs.astral.sh/uv/getting-started/installation/) 選擇適合 Windows 的安裝方式；完成後一樣要用 `uv --version` 確認。

## 步驟 2：建立課程專案

**目的：** 將本課的程式、套件與資料集中在同一個資料夾。

在 PowerShell 依序執行：

```powershell
mkdir aiot-course
cd aiot-course
uv python pin 3.12
uv init --bare
```

預期結果：目前資料夾會出現 `pyproject.toml` 與 `.python-version`，而 `pyproject.toml` 的 `requires-python` 以 Python 3.12 為基準。

!!! note "為什麼要指定 3.12？"
    `uv init` 會依目前已指定的 Python 版本建立專案需求，因此要先執行 `uv python pin 3.12`，再執行 `uv init --bare`。教室電腦統一使用 Python 3.12，教師提供的程式與套件便會在相同版本下執行，較容易排錯。

## 步驟 3：加入本課套件

**目的：** 讓專案可以讀取序列埠、處理資料、繪圖與建立 Gradio 儀表板。

執行位置：PowerShell／電腦

```powershell
uv add pyserial pandas matplotlib gradio requests
```

這個指令會建立 `.venv`，並更新 `pyproject.toml` 和 `uv.lock`。

套件用途如下：

| 套件 | 用途 |
| --- | --- |
| `pyserial` | 讓 Python 透過 USB 序列埠和 ESP32 通訊 |
| `pandas` | 整理 CSV 與感測資料 |
| `matplotlib` | 繪製溫度、濕度等資料圖表 |
| `gradio` | 建立電腦本機使用的互動儀表板 |
| `requests` | 進行 HTTP 請求；用於延伸的網路通訊情境 |

## 步驟 4：確認套件可用

**目的：** 在開始寫程式前，先確認套件真的安裝在本課專案環境中。

執行位置：PowerShell／電腦

```powershell
uv run python -c "import serial, pandas, matplotlib, gradio, requests; print('套件匯入成功！')"
```

預期結果：

```text
套件匯入成功！
```

!!! tip "之後怎麼執行 Python 程式？"
    在 `aiot-course` 資料夾中使用 `uv run python 檔名.py`。例如：`uv run python hello.py`。本課不要求你手動啟用 `.venv`。

## 步驟 5：讀取一筆模擬感測資料

**目的：** 先認識後續 UART 會使用的 JSON 資料格式。

建立檔案 `read_json.py`，內容如下：

執行位置：Python／電腦  
檔案：`read_json.py`

```python
import json

raw_line = '{"type":"sensor","temp":25.4,"humidity":61.0}'
data = json.loads(raw_line)

print(f"溫度：{data['temp']} °C")
print(f"濕度：{data['humidity']} %")
```

執行位置：PowerShell／電腦

```powershell
uv run python read_json.py
```

預期結果：

```text
溫度：25.4 °C
濕度：61.0 %
```

!!! note "JSON 是什麼？"
    JSON 是用欄位名稱與值來表示資料的文字格式。例如這一筆資料有 `type`、`temp`、`humidity` 三個欄位。後續 ESP32 會用相同概念傳送感測資料給 Python。

## 常見問題

### PowerShell 顯示找不到 `uv`

1. 關閉目前的 PowerShell 視窗後重新開啟。
2. 再執行 `uv --version`。
3. 如果仍找不到，請詢問教師或助教，確認 uv 是否已完成安裝與 PATH 設定。

### `uv add` 失敗或一直無法下載

1. 確認電腦目前可以上網。
2. 確認你位於 `aiot-course` 資料夾：執行 `Get-Location`。
3. 不要改用全域 `pip install`；先保留錯誤畫面並請教師或助教協助。

### 執行時出現 `ModuleNotFoundError`

1. 確認你在有 `pyproject.toml` 的 `aiot-course` 資料夾中。
2. 使用 `uv run python read_json.py`，不要只輸入 `python read_json.py`。
3. 必要時重新執行 `uv add pyserial pandas matplotlib gradio requests`。

### JSON 解析出現錯誤

1. 檢查 JSON 的雙引號是否仍是半形 `"`，不是全形或彎引號。
2. 檢查 `{`、`}`、逗號與欄位名稱是否完整。
3. 先使用本頁提供的 `raw_line` 測試，再修改數值。

## 重點整理

- `uv` 會管理本課的 Python 套件與虛擬環境。
- `.venv` 是專案專用的套件空間，不需要手動啟用。
- `pyproject.toml` 記錄套件需求，`uv.lock` 固定安裝版本。
- 使用 `uv run python 檔名.py` 執行本課 Python 程式。
- JSON 可以把感測資料用欄位名稱與數值傳遞給 Python。

## 延伸練習（可選）

將 `raw_line` 中的溫度與濕度改成自己的數值，再多加入一個 `device_id` 欄位，例如 `"device_id":"esp32-01"`。試著用 `print()` 顯示這個欄位。
